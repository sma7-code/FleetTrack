# FleetTrack

Requirements: JDK 21, MySQL running on localhost:3306.
DB credentials: edit `local.properties` (database is auto-created).

## Run
Windows:  mvnw.cmd spring-boot:run
Mac/Linux: ./mvnw spring-boot:run

## IntelliJ
File > Open > select pom.xml > Open as Project. Wait for Maven import, set Project SDK = 21,
then run FleettrackApplication.
